# STFiLM — Metadata-Conditioned FiLM on top of STFlow

*Summary of work. Date: 2026-07-30.*

## 1. The idea

**Condition an accepted H&E→spatial-transcriptomics model on cheap, inference-time-available
sample information (via FiLM) so that a *single* model generalizes across organs — instead of
training a separate model per tissue.**

- **Problem.** Existing models (STFlow, Stem, HisToGene, Hist2ST) are trained per-dataset. On an
  organ they never saw, they collapse (our LOOO: kidney/prostate ~0.12, liver ~0.04, vs ~0.77
  in-distribution).
- **The free lever.** Gene expression is the *target* (unavailable at inference), but the
  **slide-level histology descriptor / organ / platform is always available at inference**. So we
  can legitimately condition on it.
- **Mechanism (FiLM / adaLN).** `γ, β = MLP(conditioner); h → γ⊙h + β` per block. Retunes one
  shared backbone to the tissue at hand instead of needing a separate model — a small, defensible
  delta on top of an already-accepted method.

**Validity rule (used throughout):** a FiLM conditioner is only usable if available at *inference*.
Histology embeddings and metadata are (green); gene expression is not (it is the target).

## 2. What our model is

**STFiLM = STFlow (ICML 2025) + a locally-added FiLM/adaLN metadata conditioner.**

- **Base:** STFlow (Zhang et al., *Scalable Generation of Spatial Transcriptomics from Histology via
  Whole-Slide Flow Matching*, ICML 2025; arXiv 2506.05361). Flow-matching model with a custom
  geometric, SE(2)-equivariant `SpatialTransformer` denoiser (frame averaging over 2D spot layout).
- **Upstream STFlow has NO FiLM.** We added it. So the contribution is *both the mechanism and the
  conditioner*.
- Two upstream bugs were worked around to run it: `GeneUpdate.__init__` didn't accept `non_negative`;
  `MLPAttnEdgeAggregation` hardcodes `+50` (gene-panel size). Neither is fixed upstream.

## 3. How & where FiLM is wired in

Three insertion points, two files. FiLM lives entirely in the **invariant scalar token stream** and
never touches the frame/edge geometric features — this preserves STFlow's SE(2)-equivariance.

### (a) FiLM primitive — `STFlow/stflow/model/transformer.py:19`
```python
def modulate(x, shift, scale):
    return x * (1 + scale) + shift      # γ=(1+scale), β=shift, per-channel
```

### (b) Applied per block (adaLN-Zero) — `transformer.py:170–197`
```python
self.adaLN = nn.Sequential(nn.SiLU(), nn.Linear(d_model, 4*d_model))
gate_msa, shift_mlp, scale_mlp, gate_mlp = self.adaLN(c).chunk(4, dim=-1)

# geometric attention: input UNTOUCHED (keeps equivariance), only OUTPUT gated
context = self.attn(gene_exp, token_embs, coords, neighbor_indices)
token_embs = token_embs + gate_msa * context

# scalar MLP path: full FiLM (this stream is invariant, so it is safe)
h = modulate(self.norm_mlp(token_embs), shift_mlp, scale_mlp)
token_embs = token_embs + gate_mlp * self.mlp(h)
```
- **adaLN-Zero init** (`transformer.py:215–219`): last adaLN Linear zero-initialized → every block
  starts as identity = un-modulated STFlow; training learns to open the gates.
- `c is None` → block runs the original upstream path (this is the `none` baseline).

### (c) Conditioner construction — `denoiser.py:127–137` (the `film` switch = our ablation)
| `film_mode` | conditioner `c` | table row |
|---|---|---|
| `none`    | `None` (no modulation) | STFlow (ICML'25) baseline |
| `context` | `img_features + time_emb`, re-injected each layer | V1 |
| `meta`    | context + `MetadataEmbedder(meta)` (organ token, null idx 0) | V2 |
| **`desc`** | context + `desc_proj(masked-mean-pool(patch embeds))` | **STFiLM (ours)** |

The winning `desc` variant builds a **continuous slide-level histology descriptor**:
```python
valid = (raw_img.sum(-1) != 0).float()             # mask padding
desc  = (raw_img * valid[...,None]).sum(1) / denom  # masked mean over spots
cond  = cond + self.desc_proj(desc)[:, None]        # broadcast to every spot
```
Because the descriptor comes from the slide's own histology, **an unseen organ still gets a real
conditioner** → no "null-token cliff" in LOOO. `MetadataEmbedder` (`denoiser.py:52`) reserves index 0
of every field as a null token (CFG / unseen categories).

## 4. Evaluation protocol (leakage-safe cross-organ)

Built on HEST-1k (10 cohorts grouped into organs to stop tissue leakage). Generated by
`make_cross_organ_splits.py`; splits used: `cross_organ_splits8`.

- **POOLED** — leave-patient-out, all organs seen → tests whether conditioning helps in-distribution.
- **LOOO** — leave-one-organ-out → tests transfer to a held-out organ.
- Shared **leakage-safe gene panel** built only from training cohorts.
- Metric: `pearson_mean` (`stflow.app.flow.test.metric_func`).

**Apples-to-apples across every model:** same UNI patch features, same folds, same per-fold 50-gene
panel, same log1p normalization, same metric. The only thing that changes is the predictor.

## 5. Baselines vs. our model

- **STFlow (ICML'25)** — same model, FiLM removed (`film=none`). The key ablation baseline; the gap
  to STFiLM = our contribution.
- **HisToGene, Hist2ST** — prior ST methods re-fit on the same UNI features (`baseline_spatial.py`).
- **Ridge, RandomForest probes** — simple regressors on UNI embeddings (`probe_baseline.py`); the floor.
- **STFiLM (ours)** — STFlow + `desc` FiLM.

> Note: we did **not** reproduce STFlow's original in-distribution benchmark, so this is *not* a
> "beat the STFlow paper" claim. The claim is: on a fair cross-organ protocol, STFiLM beats
> unconditioned STFlow and prior ST methods.

### Takeaways
- **STFiLM is best overall in both regimes** and wins nearly every fold. Ordering:
  `STFiLM > STFlow > HisToGene > {Ridge, Hist2ST} > RF`.
- **FiLM gain over STFlow:** LOOO +0.011, POOLED +0.008 — modest but consistent across seeds/folds.
- **Gain concentrates where the theory predicts** — the collapsed-but-recoverable organs:
  pancreas +0.030, prostate +0.023, kidney +0.017 (LOOO, desc vs none).
- **Honest limit:** liver stays ~0.04 for *every* method → a data/transfer limit, not a method gap.
- **Only exception:** LOOO colorectal, where HisToGene (0.747) edges STFiLM (0.728) — plausibly seed
  noise (see caveat).

## 7. Caveats / open items
- **Seed asymmetry:** STFlow/STFiLM have 3 seeds; baselines have 1. The only place it matters is LOOO
  colorectal. Running HisToGene/Hist2ST/probes at seeds 2–3 would make the comparison fully symmetric.
- No paired significance test yet (3 seeds); several Δ are near the seed spread.
